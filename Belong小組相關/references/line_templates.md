# LINE 群組通知與提醒文案範本

本文件提供小組場地管理員在 LINE 群組或發送給小組長時可直接使用的標準化文案範本。

---

## 範本 1：每週小組租借規則提醒 (Weekly Rule Reminder)

```text
📢【Belong 小組場地租借注意事項與愛護提醒】

平安！各位小組長與區長：
感謝大家每週活潑的小組聚會！為了維護良好且舒適的聚會環境，請大家在借用場地時共同遵守以下原則：

1. ⏰ 【準時場復】：請於租借時間結束前 10 分鐘開始進行復原，讓下一時段的小組能準時開始。
2. 🧹 【環境清潔】：聚會後請將垃圾/飲料杯隨手帶走，若有食物殘渣請整理至垃圾桶。
3. 💡 【電源檢查】：離開前請確認「冷氣、電燈、投影機/電視、音響設備」皆已關閉。
4. 🪑 【桌椅歸位】：請依照場地原有的桌椅擺設圖恢復原狀。

讓我們一起做神家裡的好管家，祝福大家本週聚會滿載主的恩典！❤️
```

## 範本 2：場地申請配對成功通知 (Booking Confirmation)

```text
🎉【小組場地租借申請確認】

平安！[小組長姓名] 組長：
您所申請的小組場地已完成排定，詳細資訊如下：

🗓 租借日期：[YYYY-MM-DD]
🕒 租借時段：[HH:MM - HH:MM]
📍 排定場地：[例如：副堂 / 多功能教室 A]
👥 預計人數：[X] 人

預祝聚會順利！若有時間調整需求，請至少提前 24 小時於群組通知，謝謝！
```

## 範本 3：場地異動 / 臨時調整通知 (Venue Change Notice)

```text
⚠️【場地臨時異動通知】

平安！各位小組長：
因應教會本週 [異動原因，例如：特別聚會預演 / 場地臨時維修]，以下小組之聚會場地調整如下：

👉 [小組名稱 A] 
- 原場地：副堂
- 調整後：多功能教室 A
- 時間：[HH:MM - HH:MM]

造成不便敬請見諒，感謝大家的配合與體諒！
```

## 範本 4：特別主日保留席 Line 公告 (Reserved Seating Announcement)

```text
🪑【特別主日｜小組保留席預約與提醒】

平安！各位小組長：
本週日 [YYYY-MM-DD] 為【[特別主日名稱]】！
教會已為各小組預留小組保留席，請組長留意以下事項：

1. 📌 保留席時間：將保留至 [主日開始前 10 分鐘]，請提醒組員準時入場。
2. 🏷 座位標示：主日當天座位上貼有 [小組名稱/區名] 標示。
3. 📩 人數確認：若保留人數有增減，請於 [星期五 18:00 前] 回覆本訊息。

期待本週日與大家一同喜樂敬拜！🔥
```
