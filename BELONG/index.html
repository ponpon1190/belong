🛠️ 給主管與 IT 團隊的共同語言

1. Dynamic RSVP Webhook

加密 Token 動態 URL，點擊即自動修改 Salesforce 欄位為 Confirmed/Cancelled。

2. LINE 官方帳號整合

以 LINE 官方帳號為主要提醒管道，於 48 小時無回應時自動觸發提醒，兼顧成本與互動率。

3. Auto-Matching Flow

依據新朋友與區長／小組長的可聚會時間進行比對；若有重疊即自動配對，若無重疊則標註待確認，IT 可協助建立欄位與例外流程。

4. Retention Dashboard

區長打卡即時連動，產出第 1~2 週留存率與轉化圖表。
